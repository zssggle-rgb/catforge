01

每日重点工作

GTM每日经营驾驶舱，一屏掌握当日关键异常、核心指标异动和AI生成的优先工作建议

页面布局
  • 顶部日期区：显示当前日期、实时数据状态，可切换日期查看历史快照
  • 异常预警卡片：价格违规、竞品调价、销量异动三类核心异常，按优先级排序
  • AI洞察区域：当日AI生成的经营摘要、核心结论和推荐优先动作
  • 核心指标趋势：销量、均价、销额三大核心指标的近7/30天走势
  • 工作任务列表：今日待办、进行中、已完成任务的汇总展示
功能说明
  • 每日早晨 8:00 自动刷新当日数据与 AI 洞察
  • 点击异常卡片可直接跳转至对应功能页查看详情
  • AI洞察支持一键生成报告、追问详情、指派任务
  • 核心指标趋势支持切换时间范围（近7天 / 近30天 / 自定义）
关键指标计算逻辑
指标计算公式说明
销量环比(今日销量 - 昨日销量) / 昨日销量 × 100%正数为上升，负数为下降
销额环比(今日销额 - 昨日销额) / 昨日销额 × 100%销额 = 销量 × 成交均价
均价波动今日均价 - 昨日均价单位：元，正数表示涨价
异常总数价格违规数 + 竞品调加数 + 销量异常数按严重程度加权统计
价格违规率违规SKU数 / 监控SKU总数 × 100%含低于底价和高于指导价两类
数据来源
  • 价格数据：京东、天猫、拼多多、抖音四大主流电商平台公开成交价，每日 03:00 抓取
  • 销量数据：电商平台销量估算 + 内部销售系统对账，每日 06:00 更新
  • AI洞察：基于当日数据自动生成，每日 08:00 刷新
  • 更新频率：每日更新一次，支持手动即时刷新

重点产品表现

聚焦核心SKU的销量、价格、份额表现，AI智能归因分析异动原因

页面布局
  • 产品选择器：支持按品牌、尺寸、价位段筛选重点产品
  • KPI指标卡：销量、均价、销额、市场份额、环比变化核心指标一览
  • 趋势图表：销量、价格、销额多维度折线趋势，支持悬停查看每日数据
  • AI归因分析：自动识别异动并给出原因拆解（竞品、促销、渠道等）
  • 产品对比表：多款重点产品横向对比
功能说明
  • 支持单产品深度分析和多产品对比两种模式
  • 点击趋势图上的异常点，AI自动弹出归因分析
  • 可导出产品表现报告（Excel / PDF格式）
关键指标计算逻辑
指标计算公式说明
市场份额本品销量 / 同价位段总销量 × 100%按价格带+尺寸段双重切分
销量同比(本期销量 - 去年同期销量) / 去年同期销量 × 100%周/月维度均支持
份额变化本期份额 - 上期份额单位：百分点
均价成交总额 / 成交总件数按渠道加权平均
数据来源
  • 销售数据：京东商智、天猫生意参谋、拼多多商家后台、抖音电商罗盘
  • 市场规模：行业第三方数据（奥维云网线上推总），月度更新
  • 更新频率：每日更新销量/价格，每月更新市场份额基准

我品价格巡检

按渠道巡检我品各SKU成交价格，自动识别低于底价/高于指导价的违规风险

页面布局
  • 价格健康度总览：合规率、违规SKU数、违规渠道分布
  • 渠道巡检列表：按渠道分类展示各SKU价格与底价/指导价对比
  • 违规详情表：违规SKU明细，含店铺、价格、违规类型、严重程度
  • 趋势分析：近7天/30天价格违规趋势图
  • 底价维护入口：支持设置和调整各SKU底价标准
功能说明
  • 支持按渠道、尺寸段、价格带、违规等级筛选
  • 点击违规记录可查看违规店铺详情和价格证据截图
  • 支持一键生成价格违规整改任务，派发至对应渠道负责人
  • 底价维护支持批量导入和单条修改
关键指标计算逻辑
指标计算公式说明
价格合规率合规SKU数 / 监控SKU总数 × 100%高于底价且低于指导价判定为合规
破价幅度(底价 - 成交价) / 底价 × 100%低于底价时计算，正数为破价
违规严重等级综合破价幅度、违规店铺数、销量占比判定分为一般 / 重要 / 紧急三级
渠道违规率该渠道违规SKU数 / 该渠道监控SKU数 × 100%分渠道独立计算
数据来源
  • 价格数据：京东、天猫、拼多多、抖音等渠道商品页实时抓取
  • 底价数据：内部价格管理系统，由价格管理员维护
  • 更新频率：每日 03:00、10:00、18:00 三次巡检，支持手动即时巡检

竞品上新提醒

竞品新品上架监测与卖点对标，辅助GTM团队快速响应市场变化

页面布局
  • 上新总览：近7天/30天竞品上新数量、重点品牌分布
  • 新品列表：按品牌、上市时间、价位段展示竞品新品
  • 卖点对标卡片：新品与我品同价位产品的卖点对比
  • 影响评估：AI评估新品对我品的潜在冲击程度
功能说明
  • 系统自动监测竞品品牌的新品上架，24小时内生成提醒
  • 支持设置关注品牌和价位段，仅推送相关上新
  • 点击新品可查看详细参数、卖点分析和与我品对标报告
  • 支持生成新品应对策略建议并派发为待办任务
关键指标计算逻辑
指标计算公式说明
新品重合度匹配卖点数量 / 总卖点数量 × 100%衡量新品与我品卖点重叠程度
冲击等级综合价位重合度、卖点重合度、品牌势能判定分为低 / 中 / 高 / 极高四级
价位差(竞品新品价 - 我品对应SKU价) / 我品价 × 100%正数表示竞品定价更高
数据来源
  • 新品数据：主流电商平台新品上架监测 + 品牌官网上新信息
  • 参数与卖点：商品详情页自动提取 + 人工审核修正
  • 更新频率：每日监测，新发现24小时内入库

竞品价格监控

追踪重点竞品价格变化，分析价差变动对我品销量的潜在影响

页面布局
  • 竞品列表：展示重点竞品SKU当前价格、价格变动、与我品价差
  • 价格走势图：我品 vs 竞品 近7/30天价格对比折线图
  • 调价记录：近期竞品调价历史明细，含调价时间、幅度、原因推测
  • 影响分析：AI预测竞品调价对我品销量的影响程度
功能说明
  • 支持自定义重点竞品列表和对标SKU
  • 竞品调价超阈值时自动推送提醒（可配置阈值）
  • 点击调价记录可查看竞品全渠道价格对比
  • 支持导出竞品价格监控周报/月报
关键指标计算逻辑
指标计算公式说明
价差比例(我品价格 - 竞品价格) / 我品价格 × 100%正数表示我品更贵
调价幅度(新价 - 旧价) / 旧价 × 100%负数为降价，正数为涨价
销量影响预估基于历史价格弹性系数 × 价差变化仅供参考，实际受多因素影响
价格竞争力指数竞品均价 / 我品均价 × 价格权重指数越高我品价格越有竞争力
数据来源
  • 竞品价格：京东、天猫、拼多多、抖音四大平台实时抓取
  • 价格弹性：基于历史销量-价格回归分析得出，季度更新
  • 更新频率：每日 10:00、16:00、22:00 三次更新

竞品洞察分析

输入我品型号，AI自动识别核心竞品并生成多维度深度对标报告

页面布局
  • 竞品搜索区：输入我品型号，AI自动筛选匹配竞品
  • 竞品雷达图：价值战场、目标客群、价格带、市场验证、价值锚点、用户任务六维对比
  • 价值战场重合结构：各竞品与我品在主战场/辅战场/机会战场的重合度
  • 市场验证表格：竞品定位、均价、销量等核心指标对比
  • 卖点对比：产品核心参数、卖点、用户评价的详细对标
功能说明
  • 支持输入任意我品SKU，30秒内生成完整竞品分析报告
  • 自动从配置、价格、客群、市场表现多维度匹配竞品
  • 点击"查看分析依据"可追溯竞品匹配逻辑和数据来源
  • 支持导出完整竞品洞察分析报告
关键指标计算逻辑
指标计算公式说明
价值战场重合度同战场卖点匹配数 / 总卖点数 × 权重主战场权重最高
综合竞争指数价格接近度×0.3 + 卖点重合度×0.3 + 客群重合度×0.2 + 市场重合度×0.20~100分，越高竞争越强
配置对标得分各核心参数对标得分的加权平均含画质、音响、智能、外观等维度
数据来源
  • 产品参数：品牌官网、电商详情页、产品白皮书
  • 市场数据：奥维云网、中怡康线上推总数据
  • 用户反馈：电商平台评论VOC分析、社媒口碑数据
  • 更新频率：产品库月度更新，市场数据季度校准

品牌溢价分析

对比我方与竞争品牌的价格指数、VOC认同及综合品牌溢价指数

页面布局
  • 综合溢价指数：品牌溢价综合得分与竞品对比
  • 价格指数趋势：近12个月各品牌价格指数走势
  • VOC认同度：用户评论中品牌正面提及率分析
  • 分维度溢价拆解：按产品线、价位段、渠道拆解溢价构成
功能说明
  • 支持多品牌横向对比和单品牌纵向趋势分析
  • 溢价变化可下钻到具体产品线和价位段
  • VOC数据支持按卖点维度查看用户提及率和情感倾向
关键指标计算逻辑
指标计算公式说明
品牌溢价比例(本品均价 - 行业均价) / 行业均价 × 100%正数表示品牌有溢价
价格指数本品均价 / 基准期均价 × 100基准期=100，反映价格变动
VOC正面提及率品牌正面评论数 / 品牌总评论数 × 100%基于评论情感分析
综合溢价指数价格溢价×0.5 + VOC溢价×0.3 + 渠道溢价×0.20~100分，综合衡量品牌力
数据来源
  • 价格数据：主流电商平台全量SKU成交价加权计算
  • VOC数据：京东/天猫/抖音评论区语义分析，月度处理评论量 500万+
  • 行业基准：奥维云网线上市场均价，月度校准
  • 更新频率：价格指数周更，VOC月更，综合指数月度校准

待办任务中心

集中管理价格整改、竞品分析、策略调整等GTM待办事项，追踪处理进度

页面布局
  • 任务概览：待处理、进行中、已完成、已逾期任务数量统计
  • 任务列表：按优先级、截止时间、负责人等多维度展示
  • 任务详情：任务描述、处理记录、相关数据证据、协作人员
  • 筛选与搜索：支持按类型、状态、优先级、负责人筛选
功能说明
  • 系统自动生成价格违规整改任务，也支持手动创建任务
  • 任务支持指派、转交、备注、附件上传等协作功能
  • 逾期任务自动标红提醒，可设置任务提醒方式
  • 支持任务处理完成后的数据验证和效果复盘
关键指标计算逻辑
指标计算公式说明
任务完成率已完成任务数 / 总任务数 × 100%按周期（周/月）统计
按时完成率按时完成任务数 / 应完成任务数 × 100%衡量团队执行力
平均处理时长Σ(完成时间 - 创建时间) / 完成任务数按任务类型分别统计
逾期率逾期任务数 / 总任务数 × 100%超过截止时间未完成即逾期
数据来源
  • 任务数据：系统内部任务管理模块
  • 自动任务：价格巡检、竞品监控等模块自动触发生成
  • 更新频率：实时更新，任务状态变化即时同步

AI对话助手

以自然语言对话方式进行竞品分析、价格查询、策略建议等智能交互

页面布局
  • 欢迎页：快捷预设问题 + 输入框，支持上传文件/图片
  • 对话区：用户消息与AI回复的流式展示，支持结构化内容
  • 底部输入区：持续对话输入框，支持多轮追问
  • 对话索引：右侧快速定位本轮对话中的问题节点
  • 历史对话：左侧边栏展示最近对话记录，支持切换和继续
功能说明
  • 支持文字输入和文件/图片上传，基于上传内容进行分析
  • 预设问题一键发起分析，涵盖竞品、卖点、价格、异常等常用场景
  • AI回复包含结构化卡片、表格、图表等可视化内容
  • 支持划词引用，选中文本即可基于该内容追问
  • 每条AI回复底部提供反馈按钮（有用/没用/复制/生成报告）
关键指标计算逻辑
指标计算公式说明
问题理解准确率用户反馈"有用"数 / 总反馈数 × 100%基于用户反馈统计
平均响应时长Σ(回复时间 - 提问时间) / 对话轮数反映AI处理速度
对话深度单场对话的总消息轮数衡量问题深入程度
数据来源
  • 知识库：产品库、价格库、市场数据、品牌数据等全量业务数据
  • 分析模型：基于价格弹性、竞品对标、量价验证等算法模型
  • 对话数据：用户对话记录用于模型优化，数据严格脱敏
  • 更新频率：知识库与业务数据同步更新（日更/周更/月更）

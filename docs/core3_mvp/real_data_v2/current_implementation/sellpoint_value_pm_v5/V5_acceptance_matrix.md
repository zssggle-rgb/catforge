# 用户卖点价值分析 V5 验收矩阵

状态：G00 冻结候选

## 1. 业务验收

| ID | 场景 | 必须看到 | 禁止出现 |
| --- | --- | --- | --- |
| B01 | 用户价值成立但不能量化 | 具体用户结果 + 量化边界 | “无价值”或伪金额 |
| B02 | 直接反事实缺失 | 市场池/参数梯度/品牌梯度/合成基线的可用结果 | 因 M14 为空而整份报告无参照 |
| B03 | 真实亮点存在 | 亮点类型、相对对象、量价承接和限制 | 所有 SKU 通用的口水结论 |
| B04 | 无亮点 | 明确空结论及原因 | 强行 Top 3 |
| B05 | 合成基线可用 | donor、平衡、差异区间、非因果标记 | “增加卖点必然增加销量” |
| B06 | 高低绩效原型 | 控制后组合特征和目标缺口 | 单卖点因果金额 |
| B07 | opportunity battlefield | 已有战场增强路径 | 写成进入新战场 |
| B08 | excluded reachable battlefield | 新拓展条件、空间、缺口、挤占 | 只靠改文案即可进入 |
| B09 | M11D 战场销量 | 当前销量语义分配 | 新增销量 |
| B10 | 价格强销量弱 | 两笔账分开展示 | 合并成“价值高” |
| B11 | 销量强价格弱 | 客户获得/市场承接边界 | 自动涨价建议 |
| B12 | cannibalization unknown | 净新增为空，显示风险边界 | 用 gross 代替 net |
| B13 | 高度共线 | 组合分析 | 拆成多个金额重复计算 |
| B14 | 产品经理报告 | 三分钟内找到亮点、量价、参照、战场方案 | 内部码、SQL、证据 ID、通用清单 |

## 2. 方法验收

| ID | 方法 | 通过门禁 |
| --- | --- | --- |
| M01 | 多层反事实召回 | 来源可追溯、角色由规则判定、拒绝原因完整、同输入确定性 |
| M02 | 同预算池 | 尺寸形态、价格窗口和共同在售一致，异常价格过滤 |
| M03 | 品牌梯度 | 同品牌同尺寸相邻层级，不混用跨尺寸升级 |
| M04 | 参数梯度 | 档位真实变化、unknown 不当 base、其他主要差异可见 |
| M05 | 同宣称不同兑现 | 宣称口径与评论口径可比，泛化体验不下钻技术 |
| M06 | 自身价格曲线 | 至少版本化周数/平台/价差门槛，不外推，方向异常时置空 |
| M07 | 合成市场基线 | overlap、balance、有效权重、placebo、leave-one 稳定性均通过 |
| M08 | 高低绩效原型 | out-of-fold/时间稳定，基础控制完整，共线限制显式 |
| M09 | 严格金额 | base、独立变化、价格/选择变化、稳定性、非外推全通过 |
| M10 | 战场优化 | entered 与 excluded 互斥；空间、可达性、挤占分离 |
| M11 | 量价分账 | allocation、gross observational、cannibalization、net 不混写 |

## 3. 数据与线路验收

- authority resolution 不静默选择多个 current；
- M03B/M04C/M05C/M07/M09C/M10C/M11C/M11D/M12D 版本和 hash 完整；
- M12C 旧金额不进入输入、模型标签或输出；
- M11D 权重不改写真实 SKU 销量；
- missing 保持 unknown；
- direct、pool、synthetic 每个样本均保存 manifest/hash；
- 真实数据 fixture 覆盖：65E7Q、直接对照可用、合成对照可用、合成失衡、价格曲线强/弱、共线、事实冲突、负向/混合价值、opportunity 已进入、excluded 可达/不可达、挤占不可识别。

## 4. 工程验收

- 公共纯函数、schema、异常和边界有单元测试；
- 新代码覆盖率目标不低于 90%，关键门禁 100% 分支覆盖；
- 相关 V2/V4/M11C/M11D/M12D/M12C 回归通过；
- 核心测试不调用外部 LLM/网络；
- JSON、短答、Markdown、飞书共用 DTO/result hash；
- 查询数不随候选数线性增长；
- 10k 行内存、单 SKU P95 满足详细设计预算；
- feature flag 默认关闭，无 flag 数据库查询为 0；
- 代码和文档 `git diff --check` 通过；
- 精确 stage，不包含现有 M12D 或其他脏工作区改动。

## 6. 65E7Q 特别断言

- 直接 M14 为空不再导致所有反事实为空；
- 至少尝试同预算、同品牌/尺寸、参数梯度、同宣称兑现、自身价格曲线和市场合成池；
- 画质组合不拆给亮度、分区、MiniLED、芯片分别计价；
- 系统流畅不证明 AI 画质；
- 主、辅、机会/用户观察战场均按已有战场处理；
- 护眼等因角色上限未升为辅战场时，优先判断 portfolio priority，而不是新战场；
- 当前价格高位、销量低位必须分开呈现，不能包装成“高端定位成立”；
- 任何销量差必须区分市场原始表现、控制后残差、合成观察性差和 M11D 分配；
- 严格金额门禁不通过时保持 null。

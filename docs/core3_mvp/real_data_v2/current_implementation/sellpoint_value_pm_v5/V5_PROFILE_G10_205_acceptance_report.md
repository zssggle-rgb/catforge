### 价格方向修复

AC r1 的实际报告验收发现，一款 SKU 曾同时显示“带来价格溢价”和“均价低 31 元”。根因是汇总层只检查了相对销量，没有要求价格差为正。

修复后，只有“本品均价更高且销量不弱”才归为当前价格得到用户价值支撑。155 款 AC 的最终分布为：

- 36 款存在正向价格支撑；
- 51 款有市场量价比较，但没有形成“均价更高且销量不弱”的价格支撑；
- 68 款暂无可展示的价格比较；
- 方向矛盾为 0。

正向样本 AC00032338：1 组用户价值形成价格支撑，最具体一组约 365 元、12.8%；销量约高 2,003.2 台/周、122.1%。

未形成价格支撑的样本 AC00026378：最具体一组均价低 31 元、1.7%，报告不再称为价格溢价。

证据不足样本 AC00034959：保留为 blocked，问答只说明当前证据边界，不给出量价取舍。

## 产品经理可以使用的分析结果

画像不是评论计数表。每个 SKU 保存并可供问答消费的内容包括：

1. 用户实际感知到哪些价值，以及正向兑现、负向反馈、部分兑现或尚未观察到；
2. 哪些用户价值组合相对其他产品形成优势或短板；
3. 当前价格是否得到用户价值和市场量价表现支撑；
4. 当前销量表现更适合通过保留价值、修正卖点、调整价格还是改变 SKU 角色来改善；
5. 参数差异是否转化成用户可感知价值；
6. 哪些投入值得继续保留，哪些尚未转化，哪些目前证据不足，不能作产品取舍。

TV 共保存 1,231 条相对价值优势判断、1,224 条价格支撑判断、1,200 条规模转化判断和 31 条参数转化判断。AC 共保存 2,796 条相对价值比较、924 条价格支撑判断、924 条规模转化判断和 36 条参数转化判断。

量价结果是基于现有市场产品、用户价值兑现和周均量价表现的市场关联量化。它可以回答“当前价格是否得到价值支撑”“同类价值组合卖得更好还是更差”，但不写成心理最高支付价、随机实验因果效应或严格单卖点净新增销量。

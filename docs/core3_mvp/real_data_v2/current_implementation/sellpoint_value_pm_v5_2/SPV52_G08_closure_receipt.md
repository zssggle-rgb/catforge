## 6. V5.1 → V5.2 差异

V5.2 保留 V5.1 已有的用户价值、候选产品、市场量价和 SKU 结论，并新增：

1. 本品宣传原文和标准卖点事实；
2. 本品卖点到支撑参数、用户价值和内部主题的可追溯链接；
3. 核心卖点、基础卖点、用户未认知卖点、待确认卖点四分类；
4. 差异化参数、基础参数、参数短板、非关键参数差异、待确认参数五分类；
5. 竞品原始卖点的“卖点机会/当前无需优先跟进”取舍；
6. 防止参数或价值主题冒充卖点的完整性计数。

因此，V5.2 不是重算或替代 V5.1 的价值和量价结论，而是在原结论上补齐产品经理熟悉的“原始卖点”入口和严格分层。

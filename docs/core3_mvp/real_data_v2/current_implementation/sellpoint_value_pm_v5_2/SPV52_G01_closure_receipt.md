## 2. 核心决策

1. 产品参数、产品原始卖点、用户价值、内部价值主题分为四层；
2. 产品卖点唯一合法来源为 M04C 原始卖点事实；
3. 参数、capability、value bundle、battlefield 和内部价值主题禁止兜底生成产品卖点；
4. 本品卖点分为核心卖点、基础卖点、用户未认知卖点、待确认卖点；
5. 参数单独分为差异化参数、基础参数、参数短板、非关键参数差异、待确认参数；
6. table-stake 有原始卖点时进入基础卖点，没有原始卖点时进入基础参数；
7. 竞品卖点机会必须同时具备竞品原始卖点、用户价值和竞争表现证据；
8. 正式 V5.1 current 保持不变，V5.2 只创建新 draft。

# SPV51-G08 低门槛量价与参数组关闭回执

状态：completed

日期：2026-07-17

## 1. 直接量价比较

- 1 个有效对照即可形成 `single` 结果，2—4 个为 `small_group`，5 个及以上为 `group`；
- 使用目标 SKU 和各对照自身已保存的全观察期周均价格、周均销量，不要求共同周或共同平台；
- 价格和销量分别选取可用行：候选缺价格只跳过价格指标，缺销量只跳过销量指标，不再使整个对照组失败；
- 每个指标独立保存实际对照 SKU、样本数、对照均值、本品差值、差异率和方向；整体证据强度采用两个指标中较弱者，避免用大价格样本掩盖小销量样本；
- 同一 SKU 同时出现在正式竞品池和市场参考池时只计一次，优先保留正式竞品身份，另一身份保存为跳过原因；
- 结果明确标记为市场量价关联，`causal_claim=false`，不要求价格先变化，也不冒充单卖点因果净增量。

## 2. 参数取值分组

- 直接使用标准化后的实际参数取值，不建立高、中、低档，也不要求参数具有顺序；
- 本品取值和至少 1 个不同取值 SKU 即可形成方向性结果，所有实际取值均保存，不截断小组；
- 每个取值组保存 SKU 数、可用价格 SKU、均价、可用销量 SKU、周均销量，以及相对本品取值组的量价差；
- 同取值的市场产品与本品共同构成本品取值组，其他实际取值逐组比较；单行缺参数只跳过该行，单行缺价格或销量只影响该组对应指标；
- 已确认的基础能力仍计算和保存量价组，但 `core_highlight_eligible=false`。HDMI 2.1 样例不会成为核心卖点，也不会阻断刷新率等其他参数或整个 SKU；
- 参数不同但市场指标不足时返回 `partial_conclusion`；没有不同取值或本品参数缺失时仅返回局部 `no_conclusion`，不触发 review。

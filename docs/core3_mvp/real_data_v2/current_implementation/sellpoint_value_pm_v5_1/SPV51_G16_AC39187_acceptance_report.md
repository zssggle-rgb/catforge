状态：passed

## 1. 先看产品结论

这款产品已经形成冷暖、空气健康、大空间、节能、安装适配和智能控制等用户价值，但当前价格没有得到销量表现的充分支撑。

四组不重复的价值组合对照都显示同一方向：本品周均价高 `150.3～233.9 元`，周均销量却低 `1281.2～4803.2 台`。因此，如果目标是扩大销量，不能继续加价后等待价值自然转化；应先验证已成立的用户价值能否改善销量，仍无改善时再下调价格，或把 SKU 明确调整为走量角色。

本品当前处于“1匹及以下挂机舒适升级款”和“走量款”的定位取舍点。继续承担升级款，需要让已有用户价值形成更强的市场转化；做不到时，价格和 SKU 角色需要同步调整。

## 2. 产品经理现在可以怎么做

### 产品定义

先保持现有产品定义，不新增配置预算。现有证据还不能判断冷暖能力与空间匹配等 8 类投入中，哪些值得继续加码、哪些已经转化、哪些仍是短板，因此不能把“未知”解释成“没有短板”。

下一步应先补齐现有投入与用户价值之间的转化判断，再决定跟进竞品配置或新增资源，避免只因竞品纸面参数不同而增加成本。

### 价格与销量

当前价格支撑存在压力。若销量优先：

1. 先强化用户已经感知到的冷暖、空气健康、节能和操作便利价值；
2. 观察这些价值是否能改善销量表现；
3. 若销量仍无改善，再下调价格或把 SKU 调整为更明确的走量款；
4. 当前不适合继续扩大加价。

### SKU 角色

本品已进入两个价值战场：

- 1匹及以下挂机舒适升级；
- 2匹挂机大房间均衡。

现阶段更重要的不是再进入更多战场，而是判断现有战场中的价值能否转化成销量。若不能，本品应从“舒适升级”转向更明确的“价格走量”角色。

# SPV51-G13 方法评审

状态：passed

日期：2026-07-17

## 1. 评审结论

V5.1 的主结果是用户价值、局部投入判断和可追溯的市场量价表现；严格 WTP、synthetic 与市场原型属于增强层。增强层没有结果时不会再抹掉直接量价、价值项、SKU 或版本结论。没有发现未解决的 P0/P1 方法问题。

## 2. 四层量化边界

1. 用户价值证据保存用户感知结果与来源，不把评论条数冒充价值金额；
2. 直接量价允许 1 个合法对照形成方向性结论，分别比较周均价格和周均销量，缺失只影响对应指标；所有结果均保存 `causal_claim=false`，业务表述明确“不归因于单一卖点”；
3. 市场原型保存同预算、高低销量组合、已有/相邻价值战场等市场参照，表达“市场中什么组合更常见、表现如何”，不表达随机实验因果；
4. strict WTP 只有在既有独立门槛通过时才显示金额，且明确不是用户心理最高价；未通过时区块省略，普通量价结果继续有效。

## 3. 候选与局部状态

- 正式竞品只来自已发布/current 的竞品画像；市场与产品设计参照单独成池；Top 3 只是优先标签，不截断 20 款正式候选；
- 每个产品问题独立选择候选，某个候选缺参数、销量或价值事实，只影响使用该维度的问题；
- `unknown`、`not_assessed` 和 optional enhancement `no_conclusion` 不传播为全局复核；只有真实数据冲突或结构异常进入局部 `invalid`。

## 4. 65E7Q 方法准备度

G02 基线确认 65E7Q 有 20 款正式竞品、51 款市场参照，旧 V5 的 5 个价值项中已有 4 个直接量价结果。V5.1 方法能够保留这些量价结果，同时用新竞品画像替代旧的“0 正式竞品”候选源。真实 V5.1 数值结论仍必须在 SPV51-G15 单 SKU draft 中验收，本评审不提前声称生产结论。

## 5. 发布边界

- 市场关联不能写成单卖点净新增销量或随机实验因果；
- 参数组差异只有在非基础能力且用户价值链成立时，才可进入核心卖点；
- `no_conclusion` 返回数据不足，不补算、不编造负面结论；`invalid` 返回数据完整性异常，不生成产品动作。

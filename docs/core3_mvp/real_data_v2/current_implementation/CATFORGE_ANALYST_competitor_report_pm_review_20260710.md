# CatForge Analyst 竞品报告产品经理视角复审

## 1. 复审范围

- 飞书样例：美的 KFR-88LW/N8KS1-1U 重点竞品分析报告。
- 本地对应报告：`ac_market_pool_v02/AC00038063_competitor_report_v02.md`。
- 生成代码：`analyst/competitor_answer.py`、`analyst/replacement_pressure.py`、M12D 预览和飞书看板渲染。
- 阅读角色：需要判断竞品优先级、产品差异和证据可靠性的产品经理，不假设读者理解 M12D、门槛 code 或算法字段。

## 2. 产品经理真正需要的信息

1. 先看谁最值得关注，以及这是强直接竞品还是同池观察对象。
2. 看它为什么进入同一次购买决策，而不是只看一组综合分。
3. 看本品核心成交理由被谁覆盖、在哪些地方仍然独有。
4. 看压力强弱、主要分流方式和结论可信度。
5. 看哪些数据是事实，哪些只是观察或待补证据。

## 3. 主要问题矩阵

| 位置 | 当前表现 | 产品经理阅读问题 | 根因 | 修改方向 |
| --- | --- | --- | --- | --- |
| 看板结论 | “优先盯”后接“低替代压力复核” | 不知道是强敌还是弱观察对象 | 相对排名与绝对压力门槛混写 | 展示“当前候选第1 + 竞争成立程度 + 压力分” |
| 看板市场验证 | 部分 SKU 显示“待复核台”，正文却有确定销量 | 同一报告数据互相矛盾 | 看板从中文摘要反向正则解析销量 | 看板和正文统一读取结构化市场字段 |
| 分析结论 | 0/15 锚点仍写“最完整替代关系” | 分数与文字结论冲突 | 固定强结论模板不看门槛 | 按成立程度生成结论，不达门槛只写相对排名 |
| 用户任务 | 60% 被写成“高度交叉” | 强度被夸大 | 固定形容词未绑定分数 | 用“高/中/低 + 百分比 + 主项是否命中” |
| 关键价值锚点 | 无共享锚点时兜底“技术型/场景型高端体验” | AC 报告出现泛化电视式结论 | 空数据使用通用营销文案兜底 | 空数据明确写“未形成可比较成交理由” |
| 替代压力 | “威胁来自低替代压力复核……因此影响成交” | 因果矛盾 | 压力类型、等级、复核状态混成一个字段 | 拆分结果、依据、业务含义和证据边界 |
| 候选附录 | 输出 snake_case 门槛代码 | 业务读者无法理解 | 原始 `gate_reasons` 直接 join | 使用统一业务语义目录解析 |
| 参数画像 | 出现 `floor_standing`、`heating_function_flag` 等 | 参数证据不可读 | 未命名 code 回退原值 | taxonomy/参数词典严格解析，未知阻断发布 |
| 分析过程 | 每章结论是固定原则，不是本次产品差异 | 看完仍不知道三款具体差别 | 章节结论模板没有消费实际分数 | 自动识别最高、最低、主项命中和关键差异 |
| 产品画像 | 画像与横向表重复，旧样例达 882 行 | 重点被大量重复明细淹没 | 主报告承担了技术审计明细 | 主报告只保留主项和差异项，完整明细留审计产物 |

| 标点与空格 | `不足。；门槛`、`不足。，因此`、型号粘连 | 降低专业可信度 | 字符串片段自行携带标点 | 句块不带尾标点，统一句子连接器规范化 |

## 4. 修改后的信息结构

### 首屏看板

- Top 3 相对排名。
- 每款竞品的竞争成立程度：已证实直接竞品、潜在替代、同池观察、暂不能判断。
- 替代压力分数和等级。
- 一句最关键的入选理由。
- 市场销量验证和证据状态。

### 分析结论

- 总判断：当前是否识别到强替代竞品。
- Top 3 各一条：为何进入 Top 3、压力多强、最关键差异。
- 统一证据边界：哪些画像缺失或降级。

### 分析过程

- 继续按购买池、价值战场、用户任务、目标客群、关键价值锚点、替代压力、市场验证分章。
- 每章输出实际分数和差异，不重复通用规则。
- 候选池只作为附录，并使用中文未入选原因。

### 产品详情

- 横向表承担四款产品的主要比较。
- 单品画像只保留主项、与本品/竞品差异和证据缺口。
- 逐战场卖点量化、内部风险标记、模块和批次信息保留在技术审计产物。

## 5. 统一实现方案

1. 增加公共业务语义 resolver，集中治理风险、缺失、门槛、模块和 taxonomy code。
2. 重构替代压力契约，拆分等级、可评估状态、压力来源、业务影响和复核状态。
3. 竞品报告、飞书看板、M12D 预览和用户卖点价值报告消费同一中文语义出口。
4. 删除报告中的固定强结论和空数据营销兜底。
5. 增加 TV/AC 报告快照、跨区域数据一致性、内部代码泄漏和中文标点测试。

## 6. 验收样例

当竞品锚点可替代性为 0/15、替代压力为 3/10 且目标核心成交理由证据不足时，报告应写：

> 格力 KFR-72LW/(72527)FNHAB-B1 是当前候选中的第一观察对象。它与本品处于同一购买池，价值战场重合较高，但尚未覆盖本品可确认的核心成交理由。当前替代压力为弱（3/10），更适合作为同池观察对象；本品核心成交理由证据不完整，暂不能判断它是否会直接改变用户的最终选择。

不得写“形成最完整替代关系”“威胁来自低替代压力复核”或“因此最可能影响最终成交判断”。

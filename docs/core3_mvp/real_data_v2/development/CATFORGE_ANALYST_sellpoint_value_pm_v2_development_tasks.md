# 用户卖点价值分析智能体 V2 Goal 任务链

## 1. 调度原则

本工作由一个持续 Goal 管理，拆成 G00–G07 八个顺序任务。10 分钟心跳只唤醒当前 Goal 并推进“第一个未完成任务”，不得越过前置闸门。每个任务都必须在执行台账写入输入、动作、验证证据、结论和下一任务后才算完成。

停止条件：

- 前置合同不成立；
- 测试失败且根因未定位；
- 205 不可达；
- 真实数据与报告数字无法回读核对；
- 用户要求停止。

停止不等于跳过。恢复后从同一任务继续，不重跑已通过阶段。

## 3. G00 文档与基线

### 输入

现有 claim value、competitor、analyst CLI、M03B/M04C/M05C/M07/M12D/M14 实现及 205 的 65E7Q 事实审计。

### 工作

- 明确“分类”和“量化”是正交维度；
- 明确评论、选择和定价证据不可跨层；
- 明确用户价值组合规则；
- 定义产品经理报告；
- 锁定无成本/无利润、无单项伪金额边界。

### 验收

需求、设计、任务链和执行台账存在；所有不可推断项有明确规则。

## 4. G01 上游合同与一致性闸门

### 工作

- 新建 Pydantic 输入输出模型；
- 仓储读取目标事实、M05C atoms、周度市场、M14 竞品及竞品事实；
- 汇总 source versions/evidence IDs；
- 实现全局与单元级 data gate；
- 不写新数据库表。

### 测试

完整、M04C 缺失、M04C 自相矛盾、M03B 缺失、M07 缺失、跨批次、M14 缺失。

## 5. G02 价值单元与评论称重

### 工作

- 建立 TV 六类价值单元注册表；
- 以评论句为去重单位；
- 排除服务履约；
- 实现直接、间接、不可归因、反向；
- 实现产品成立度与用户感知重量；
- 单技术点不满足独立条件时标记组合测试。

### 65E7Q 闸门

“好高清/画面清晰”不得直接支持 MiniLED、5200nit、1920 分区；300Hz 和芯片不得从泛化评论获得 E3/E4。

## 6. G03 市场选择与定价

### 工作

- 构造同尺寸价格邻域周平台池；
- 计算 L0/L1 描述；
- 实现确定性局部价格响应；
- 计算同价选择指数；
- 仅在 L3 输出选择保持价差；
- 生成当前、-5%、+5% 情景；
- 所有金额留在组合/整机层。

### 测试

价格方差不足、正弹性、样本不足、促销污染、极端值、零销量、稳定负弹性。

## 7. G04 竞品边界

### 工作

- 优先读取 M14 当前 selection；
- 保留 slot、role、selection evidence；
- M14 缺失时回退现有 competitor-set；
- 对每个价值单元只比较产品事实、用户反馈、市场位置；
- 不复制竞品长报告，不把 M12C/M12D 结论重复计证。

### 验收

竞品 ID 与既有资产一致；V2 内没有新的 ranking/selection score。

## 8. G05 输出与 CLI

### 工作

- 新 SOP `sellpoint-value-pm`；
- 新 schema `sellpoint_value_pm_v1`；
- 产品经理短答、称重总表、单元详情、价格情景、测试清单；
- 飞书文档与卡片；
- 自然语言路由覆盖“卖点称重、用户怎么看卖点、价格承接、支付意愿定价”；
- 旧 `sku-claim-value` 路由与契约回归。

## 9. G06 本地验收

必须执行：

- 新服务/报告/CLI 测试；
- analyst 现有相关回归；
- lint/编译检查；
- 65E7Q 本地真实数据库或固定快照验收；
- 报告禁词与伪金额扫描。

失败必须记录根因和修复，不得只重跑。

## 10. G07 提交与 205

### 提交

- `git status` 核对用户既有改动；
- 只 `git add` 本任务文件；
- 查看 staged diff；
- 提交信息说明 V2 并行、证据边界与产品经理输出。

### 部署与验收

1. 检查 205 SSH、容器、health/ready；
2. 使用仓库既有部署脚本同步本次提交；
3. 运行目标测试/编译检查；
4. 用 `65E7Q` 与 `TV00029112` 分别解析，确认同一 SKU；
5. 运行 `sellpoint-value-pm --answer-style xiaoao --with-report feishu-doc`；
6. 保存 JSON 和 Markdown 证据；
7. 回读飞书文档，核对称重表、价格边界、竞品来源、数据问题；
8. 将 URL、commit、批次、方法等级、样本和限制写回执行台账；
9. 停止 10 分钟心跳并完成总 Goal。

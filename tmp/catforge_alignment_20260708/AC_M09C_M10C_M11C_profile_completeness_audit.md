# AC M09C/M10C/M11C 画像完整性复核

时间：2026-07-08

## 结论

AC 的 M09C/M10C/M11C 画像表在当前 `category_code=AC` / `batch_id=m00_20260624000202_1150a669` 下都有 155 个 SKU 行覆盖，但不能认为“每个 SKU 都已经有可供智能体直接消费的画像”。

当前缺的是主画像 code 完整性：

| 模块 | profile 行覆盖 | 有主 code 的 SKU | 主 code 缺口 |
| --- | ---: | ---: | ---: |
| M09C 用户任务 | 155 | 143 | 12 |
| M10C 目标客群 | 155 | 141 | 14 |
| M11C 价值战场 | 155 | 128 | 27 |

因此，AC M11D/M12C 前必须增加 AC M09C/M10C/M11C 画像完整性补齐任务，不能只按表行数验收。

## 方案修正

已在总计划中新增 G08：`AC M09C/M10C/M11C 画像完整性补齐`。

验收不再只看 155 行覆盖，而是要求：

- 每个 SKU 有主用户任务，或明确 unknown/review reason。
- 每个 SKU 有主目标客群，或明确 unknown/review reason。
- 每个 SKU 有主价值战场，或明确 unknown/review reason。
- 缺主 code 不能静默进入 M11D/M12C。
